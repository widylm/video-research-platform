# Один пробный поиск публичных ссылок

Браузерный адаптер можно проверить только на площадке, которая разрешила автоматизированное чтение конкретной страницы поиска для этого пилота. Общедоступность страницы сама по себе такого разрешения не даёт. При отсутствии разрешения на браузерный сбор для Instagram предусмотрен отдельный путь через официальный Hashtag Search и одобрение Meta. [TikTok Terms of Service](https://t.tiktok.com/legal/page/us/terms-of-service/en) · [Автоматизированный сбор данных Meta](https://www.facebook.com/legal/automated_data_collection_terms) · [Instagram Public Content Access](https://developers.facebook.com/documentation/development/features-reference/instagram-public-content-access)

1. Согласовать площадку, один запрос и право получать и сохранять ссылки и метаданные. Получить отдельное подтверждение на обновление `kadr-cloud-browser-executor` и `kadr-cloud-browser-preview`. Проверить текущий Workers Free и квоту Browser Run до обновления.
2. В тестовые конфигурации обоих Workers внести `KADR_ENABLE_SOCIAL_DISCOVERY=1` и `KADR_SOCIAL_DISCOVERY_PLATFORM=tiktok` либо `instagram`, с одним и тем же значением. В существующем защищённом превью сохранить проверку тестового UID и передать `cloudBrowserSocialPlatform()` в `socialPlatform` компонента `CloudBrowserSearch`. Доступ приложения к рабочему каталогу для этого пилота не требуется. Проверить конфигурации через Wrangler `--dry-run` перед публикацией. На экземпляре разрешён один пробный запуск с максимум 10 уникальными ссылками. Состояние пилота хранится отдельно в том же пространстве Durable Objects.
3. Войти тестовой учётной записью, отправить согласованный запрос один раз. Для Instagram вводится точный хэштег. Сборщик открывает одну страницу, принимает только канонические ссылки на ролики и сохраняет неизвестные поля как `null`. Истёкший срок ожидания, требование входа, CAPTCHA и ответы HTTP 401, 403, 429 и 451 показываются отдельно. При пустой выдаче фиксируется ноль найденных ссылок. Дополнительный запуск требует нового согласования.
