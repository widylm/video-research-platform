# Кадр: реальный TikTok keyword search через EnsembleData (один пробный запрос)

В PR #22 добавлен **неофициальный TikTok-провайдер** EnsembleData; это не прямое разрешение TikTok и не официальный TikTok API. Он заменяет необходимость открытия TikTok из Cloudflare Chromium для теста по словам. Один пробный запрос расходует **1 unit** согласно тарифу провайдера, без пагинации. По документации https://ensembledata.com/guide/guides/tiktok/keywords/ ответ имеет формат `data.data` (до 20 роликов); адаптер выбирает максимум 10 уникальных ссылок.

**Первый запуск не был произведён.** Реальные ссылки и формат действительного ответа ещё не подтверждены; unit-test fixtures не считаются данными TikTok. Покупки не выполняются автоматически; бесплатная пробная квота и условия хранения данных требуют проверки в аккаунте провайдера. Сравнить https://ensembledata.com/pricing и условия https://ensembledata.com/terms. Обязательно согласовать право хранить метаданные в командном каталоге до добавления постоянного сохранения.

## Безопасное включение существующего preview

1. Владелец создаёт бесплатный trial аккаунт EnsembleData **без карты и платной подписки** и берёт API token. Токен передаётся в secret **только Worker** `kadr-cloud-browser-executor`; не в репозиторий, не в ChatGPT, не в Next.js UI, не в общие vars; настройка через Wrangler secrets/Cloudflare dashboard.
2. После отдельного разрешения на обновление двух существующих тестовых Workers: preview `kadr-cloud-browser-preview`, executor `kadr-cloud-browser-executor`. Никаких действий с production Worker или Supabase. В обоих staging Worker выставить `KADR_ENABLE_ENSEMBLEDATA=1`, но `ENSEMBLEDATA_TOKEN` только в executor. Не трогать `KADR_ENABLE_SOCIAL_DISCOVERY` — браузерный режим не нужен.
3. Выполнить `npm run check`, `npm run cf:build`, `npm run test:e2e`, `wrangler deploy --dry-run` для обоих. Только после разрешения — staging deploy.
4. Открыть тестовый «Кадр» с существующей командной авторизацией → «Массовый поиск» → ключевое слово, например `street style` → «Найти» **один раз**.
5. Сохранить фактические canonical URL результатов, число роликов и реальные метрики; любые недоступные поля = `null`. Один платный в единицах API-запрос на staging ограничен флагом `provider-attempt-used` в Durable Object; повтор без отдельного согласования недоступен. Если провайдер вернёт ошибку или формат не совпадёт, её нужно исправить по **реальному санитизированному ответу** без раскрытия токена и без новых списаний.

## Лимиты пилота

- Только TikTok, только keywords; Instagram ещё не подключён.
- Только первый набор до 10 видео из 1 страницы, без автоматического повторения запросов и без скрытых/private endpoints или обхода CAPTCHA.
- Результаты видны в разделе пилота и сохраняются в job состоянии тестового Durable Object; **в рабочий каталог не пишутся**.
- Метрики считываются только когда имеются в ответе. Собрать 500–1000 видео бесплатно в рамках одного такого вызова нельзя, реальную стоимость нужно обсчитать после подтверждения первого результата.
